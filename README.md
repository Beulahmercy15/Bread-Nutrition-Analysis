# 🥖 Power BI Dashboard — Bread Nutrition Analysis

An interactive Power BI dashboard developed to analyze and compare the nutritional characteristics of 50+ bread products.

## 📊 Project Overview

This project focuses on analyzing nutritional composition, product characteristics, pricing, and other attributes of different bread products using Microsoft Power BI.

The dashboard provides interactive visualizations to compare products and identify nutritional patterns.

## 🎯 Objectives

- Analyze nutritional composition across bread products
- Compare protein and fiber content
- Analyze sodium levels
- Compare calorie values
- Analyze wheat and maize composition
- Compare product pricing
- Analyze preservatives and colors
- Create interactive and easy-to-understand visual reports

## 💡 Key Insights

The dashboard enables users to:

- Compare nutritional characteristics across products
- Identify products with higher or lower protein content
- Compare fiber levels
